# Skills Monorepo Docs

This directory holds focused root documentation for the skills workspace. Local
skills now live under root `skills/*`; child collection docs are historical
provenance only.

## Index

- `repository-layout.md`: ownership boundaries for root, linked external
  sources, and skill artifacts.
- `collection-taxonomy.md`: marketplace group taxonomy, external linked source
  model, and routing rules for placing new skills.
- `product-build-lifecycle.md`: product build lifecycle overlay from product
  facts to prototype projection, optional verification, and downstream build
  workflows.
- `generic-web-skills.md`: generic Web skill layering and source disposition
  notes.
- `design-system-format.md`: design-system format notes.
- `skill-authoring.md`: repository-wide trigger contract and manual-entry rules
  for skills.
- `repo-architecture/`: repository placement, migration, validation, and
  historical scaffold templates.
- [Repository maintenance](../MAINTENANCE.md): publication, required checks,
  GitHub settings and review status.
- `provenance/`: historical migration and distillation records.

## Root Scope

Keep this directory focused on root rules, lifecycle overlays, marketplace
groups, repository architecture, and provenance. Put single-skill policy,
examples, templates, and workflow-specific notes inside the owning skill.
