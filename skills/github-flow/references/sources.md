# Primary sources

- [Git commit DISCUSSION](https://git-scm.com/docs/git-commit#_discussion): commit message structure.
- [Git interpret-trailers](https://git-scm.com/docs/git-interpret-trailers): commit trailer format.
- [Git config](https://git-scm.com/docs/git-config): signing settings `gpg.format`, `user.signingKey`, and `commit.gpgSign`.
- [GitHub flow](https://docs.github.com/en/get-started/using-github/github-flow): the branch-based change, pull request, review, merge, and cleanup model.
- [Linking a pull request to an issue](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/linking-a-pull-request-to-an-issue): closing keywords and issue linkage.
- [Commit signature verification](https://docs.github.com/en/authentication/managing-commit-signature-verification/about-commit-signature-verification): signed commits and GitHub verification status.
- [Commits with multiple authors](https://docs.github.com/en/pull-requests/committing-changes-to-your-project/creating-and-editing-commits/creating-a-commit-with-multiple-authors): human co-author attribution with `Co-authored-by` trailers.
- [Merge methods on GitHub](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/configuring-pull-request-merges/about-merge-methods-on-github): merge commits, squash merging, and rebase merging.
- [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/): commit subject syntax and breaking-change notation.
