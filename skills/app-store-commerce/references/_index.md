# App Store Commerce References

Load only the file needed for the current operation:

- `official-commerce-sources.md`: Apple and RevenueCat authority hierarchy and
  current-source pointers.
- `pricing-and-availability.md`: territory pricing, price schedules,
  availability, dry-run planning, and optional backend command shapes.
- `iap-subscription-localization.md`: IAP, subscription, and subscription group
  localization workflows and locale handling.
- `revenuecat-catalog-reconciliation.md`: App Store Connect to RevenueCat
  product, entitlement, offering, and package reconciliation.
- `live-operation-safety.md`: confirmation gates for pricing/catalog writes.
- `commerce-manifest.md`: local JSON manifest shapes accepted by
  `scripts/catalog_drift.py`.
