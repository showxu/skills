# Fixture organization maintenance

This synthetic shared standard is authoritative for member repositories.
The default branch is `trunk`. Squash merge only, PR title and empty body,
merged branches deleted. Branch protection requires signed commits, two
approving reviews, resolved threads and `policy` and `validation` checks.
Release tags are signed annotated `v*` and immutable, with no bypass actors.
Shared community defaults are available; members do not duplicate them.
