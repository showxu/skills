# Localization

## Locale Matrix

Track each localized asset set with:

- locale
- device type
- source capture path
- localized headline or visible text
- alt text
- export path
- review status
- notes for text expansion, RTL layout, or cultural adaptation

## Rules

- Localize visible text in screenshots and feature graphics when the market
  deserves a localized listing.
- Do not literally translate headlines if the result becomes long or awkward.
  Rewrite for the target market while preserving the product promise.
- Re-check line breaks per locale. German, French, Portuguese, and many Indic
  languages may need shorter claims.
- For RTL languages, mirror asymmetric layouts intentionally and verify that
  app UI captures still match the actual product behavior.
- Localize alt text. Do not reuse English alt text for non-English assets
  unless the listing intentionally stays English.
- Avoid market-specific legal, medical, financial, price, or promotional
  claims unless the user supplies approved copy.
