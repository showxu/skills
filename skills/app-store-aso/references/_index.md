# App Store ASO References

Read only the files needed for the current ASO task.

- `official-apple-sources.md`: Apple authority, field limits, and official
  product-page surfaces.
- `metadata-keywords.md`: keyword hygiene, field utilization, and metadata
  optimization rules.
- `listing-creative.md`: screenshots, app previews, icons, Custom Product
  Pages, Product Page Optimization, and in-app events.
- `localization-and-markets.md`: locale coverage, market-specific keyword
  work, and cross-locale checks.
- `measurement-and-tools.md`: App Analytics, PPO/CPP measurement, competitor
  evidence, and optional external tools.
- `advisory-claims.md`: unsupported or unstable upstream claims that must stay
  advisory unless verified.
