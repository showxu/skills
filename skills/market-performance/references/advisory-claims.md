# Advisory Claims

Use this reference when a market performance task includes ranking formulas,
algorithm explanations, conversion multipliers, or broad growth claims.

## Treat As Advisory Unless Verified

- fixed ranking factor weights
- "2025 algorithm" or similar dated formula claims
- guaranteed conversion uplift percentages
- claims that update frequency directly improves ranking
- claims that one screenshot, keyword, ad structure, or SEO change always
  causes a fixed result
- third-party benchmark numbers without source, segment, sample, or date
- conclusions from small samples or mixed channels

## Safer Handling

- Restate the claim as a hypothesis.
- Ask what source or export supports it.
- Check whether the platform has an official source for the behavior.
- Propose a measurement plan rather than asserting the claim.
- Label the confidence: official, measured, directional, advisory, or
  unsupported.

## Report Language

Use:

```text
The supplied data supports a directional improvement in ...
```

Avoid:

```text
This proves the algorithm rewards ...
```

Use:

```text
This is worth testing because the change aligns with the observed segment ...
```

Avoid:

```text
This will increase conversion by ...
```
