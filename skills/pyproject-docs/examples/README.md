# Examples

These examples show expected target trees and normalization outcomes for
`pyproject-docs`.

They are illustrative, not automation. The authority is the role boundary and
selected profile, not a file-for-file copy of any example.

## Files

- `minimal-export-preview.md`: expected output for the minimal profile.
- `standard-export-preview.md`: expected output for the standard profile.
- `standard-target-tree.md`: common normalized Python repository shape.
- `route-in-readme.md`: route/index collision and normalization.
- `proposal-in-architecture.md`: proposal/truth collision and normalization.
