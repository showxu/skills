# Interaction Design References

Use these files only when the task needs deeper structure than `SKILL.md`.

## Index

- `interaction-models.md`: flow, state, control, navigation, and feedback
  patterns.
- `canonical-model-template.md`: structured source artifact template for
  interaction models, state machines, projection coverage, and handoff notes.
- `canonical-model-example.md`: completed interaction model example.
- `permission-handoffs.md`: blocked-state and system-permission handoff
  patterns, including macOS TCC-style drag authorization.
- `review-rubric.md`: review checklist for clarity, efficiency,
  accessibility, recovery, and product-decision handoff.
- `product-source-ledger.md`: provenance for absorbed product interaction
  model behavior.
- `canonical-model-eval-fixtures.md`: durable behavior fixtures for model
  generation and boundary checks.
- `resource-capture.md`: rules for collecting local research artifacts from
  public design/prototyping resources, including Rive `.riv` runtime files.
- `research/`: formal app-level research reports and supporting app artifacts
  for interaction and UI-layer schema work. These are facts-first references,
  not the active schema.
- `research/schema-facts.md`: promoted field-level facts from the app reports
  and artifact probes for future `UI Design Schema` and
  `Interaction Design Schema` synthesis.
- `research/apps/*.schema.yaml`: per-app machine-readable schema fact stores
  with objects, fields, evidence, draft schema mappings, decisions, and gaps.
- `flinto-state-cleanup.md`: script usage and safety rules for explicit local
  Flinto cache, Application Support, and container-state cleanup.
