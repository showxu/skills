# Example Captures

This directory holds filled example captures and example-capture seeds for
`code-to-arch`.

Example captures are teaching artifacts for future orchestrator behavior. They
are not formal eval proof, not architecture truth, and not curated cases. This
skill does not keep scaffolded `knowledge/cases/` entries by default; create
that destination only after a later Case Capture Gate promotes a capture.
