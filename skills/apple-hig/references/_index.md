# Apple HIG References

Use these files when the task needs source hierarchy or platform visual-system
rules that are too detailed for `SKILL.md`.

## Index

- `official-sources.md`: official Apple source hierarchy and lookup guidance.
- `apple-platform-visual-system.md`: HIG, Design Resources, native primitive,
  and donor-app decision rules.
- `swiftui-hig-metrics.md`: official HIG numeric guardrails for
  SwiftUI-adjacent review.
- `hig-audit-scorecard.md`: optional HIG audit scorecard and quick checklist
  for scored reviews or comparable quality passes.
- `trigger-fixtures.md`: example prompts that should or should not route to
  `apple-hig`.
