# Host Compatibility

This skill is a local Codex/OpenAI Web app implementation skill.

## Codex Behavior

- Use local repository files and commands as the implementation authority.
- Prefer existing project framework, router, state, styling, data, and test
  conventions.
- Use Browser/Playwright or `webapp-testing` for rendered evidence when the
  task requires browser verification.
- Do not claim Figma MCP, image generation, or browser QA ownership.

## Non-Claims

- This skill does not own product requirements or interaction behavior.
- This skill does not own visual concept direction.
- This skill does not create single-file HTML artifacts by default.
- This skill does not own backend/service implementation beyond frontend
  integration points.
- This skill does not guarantee production readiness without project-specific
  validation evidence.
