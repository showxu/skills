# Copy Review

## Product Page Copy

Good metadata is specific, truthful, and easy to scan.

- App name: brand plus only essential descriptor if it fits.
- Subtitle: one clear value proposition, not a keyword dump.
- Description: explain who the app is for, what it does, and why it is useful.
- Promotional text: current news or hook, not a second description.
- Keywords: compact search terms, comma-separated, no spaces after commas unless
  a phrase requires a space.

## Claim Safety

Flag claims that need evidence or owner approval:

- awards, rankings, press quotes, user counts, revenue, or download claims
- medical, financial, legal, regulated-device, child-safety, privacy, or
  security claims
- "guaranteed", "best", "most accurate", "fully private", "anonymous", or
  compliance statements
- availability in countries or platforms not confirmed by the release plan

## Keyword Hygiene

- Do not duplicate words from app name or company name in keywords.
- Avoid competitor names and trademarks.
- Remove spaces after keyword commas to save bytes.
- Do not use the same keyword list for every locale unless intentionally
  validated.
- Prefer local search intent over literal translation.

## Description Hygiene

- Use plain text, not HTML.
- Keep paragraphs short.
- Prefer benefits backed by features.
- Avoid stuffing keywords into unnatural sentences.
- Include support or subscription caveats only when accurate and required.
