# Official Search Sources

Last checked: 2026-04-30.

Use official sources before treating search behavior as a rule:

- Google Search Essentials:
  https://developers.google.com/search/docs/essentials
- Google SEO Starter Guide:
  https://developers.google.com/search/docs/fundamentals/seo-starter-guide
- Google Search Console Performance report:
  https://support.google.com/webmasters/answer/7576553?hl=en
- Google title links:
  https://developers.google.com/search/docs/appearance/title-link
- Google meta descriptions and snippets:
  https://developers.google.com/search/docs/appearance/snippet
- Google robots.txt:
  https://developers.google.com/search/docs/crawling-indexing/robots/intro
- Google canonicalization:
  https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls
- Google structured data general guidelines:
  https://developers.google.com/search/docs/appearance/structured-data/sd-policies

## Authority Rules

- Official Google documentation is the rule source for Google Search behavior,
  eligibility, spam policies, Search Console metrics, and supported features.
- Third-party SEO tools can identify candidates and compare competitors, but
  they are not ranking authority.
- Search results are personalized and time-sensitive. A manual search result
  screenshot is evidence, not a stable rule.
- Do not import or rely on exact ranking factor weights unless an official
  source states them.
