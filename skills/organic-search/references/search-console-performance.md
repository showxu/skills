# Search Console Performance

Use this reference when interpreting Search Console data.

## Metrics

Search Console performance reports commonly include:

- clicks
- impressions
- click-through rate
- average position

Common dimensions include:

- queries
- pages
- countries
- devices
- search appearance
- dates

## Interpretation Rules

- Average position is an average of the topmost result from the site in the
  selected grouping. It is not a fixed rank for every user.
- Query and page data can shift with personalization, location, device,
  history, SERP features, and date range.
- Compare query/page pairs, not only site totals.
- Segment branded and non-branded queries when possible.
- Separate discovery problems from clickability problems:
  low impressions may be indexing, relevance, or demand; high impressions
  with low CTR may be title, snippet, intent mismatch, or SERP competition.

## Report Shape

```text
Search Console Readout

Date range:
Filters:
Top query/page movements:
CTR concerns:
Indexing or search appearance notes:
Likely causes:
Competing explanations:

```

## Data Requests

When data is missing, ask for:

- export date
- Search type
- date range
- query, page, country, device, and search appearance dimensions
- list of known page, title, content, redirect, or indexing changes
