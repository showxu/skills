# SERP Presentation

Use this reference for title links, meta descriptions, headings, and snippet
review.

## Title Link Review

- Each important page should have a descriptive, page-specific title.
- Put the primary topic, product, category, or page purpose near the front.
- Avoid repeating boilerplate across many pages.
- Avoid keyword stuffing and misleading clickbait.
- Keep the title aligned with visible page content and main heading.

## Meta Description Review

- Write a concise page-specific summary for users.
- Include the decision-relevant point: what the page is, who it is for, and
  what action or information it offers.
- Do not treat meta descriptions as a ranking formula.
- Avoid duplicating the same description across many pages.
- Avoid claims that the page does not support.

## Query Intent Fit

Classify the likely intent:

- navigational: user wants a known product, company, or page
- informational: user wants explanation or guidance
- commercial: user is comparing options
- transactional: user wants to buy, sign up, download, or contact

Adjust the title, description, headings, and section order to match the
intent, but keep the page honest.

## Snippet Rewrite Shape

```text
URL:
Likely query intent:
Current title:
Proposed title:
Current description:
Proposed description:
Visible content changes needed:
Risk notes:
```
