# UX Writing Reference Index

Use this index only when `SKILL.md` routing is not enough.

## Read Order

- `copy-patterns.md`: read the section that matches the surface: action,
  alert, confirmation, error, empty state, onboarding, permission, setting,
  tooltip, inline help, notification, or status message.
- `voice-and-terminology.md`: read when product voice, tone, terminology, or
  repeated naming is unclear.

## Routing

- User state, task flow, decision point, or missing screen states:
  use `interaction-design`.
- Apple platform wording, alert/action semantics, or component conventions:
  use `apple-hig`.
- Source strings, CLI output, accessibility label wording, localization
  readiness, or implementation handoff:
  use the implementation-side interface writing skill when available.
- String Catalogs, `.xcstrings`, XLIFF/xcloc, pseudolocalization, or RTL
  engineering checks:
  use `xcode-localization-patterns`.
- VoiceOver behavior, traits, reading order, or assistive-technology testing:
  use `accessibility-patterns`.
- App Store, launch, landing page, ad, or screenshot marketing copy:
  use market-facing messaging skills.
